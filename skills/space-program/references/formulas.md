# 规划与空间计算公式

根据任务选择公式。先确认当地定义，例如计容建筑面积、建筑基底面积和绿地面积的纳入规则。

## 用地与建筑量

```text
容积率 = 计容建筑面积 / 用地面积
计容建筑面积 = 用地面积 x 容积率
用地面积 = 计容建筑面积 / 容积率

建筑密度 = 建筑基底总面积 / 用地面积 x 100%
建筑基底总面积 = 用地面积 x 建筑密度

绿地率 = 计入绿地面积 / 用地面积 x 100%
计入绿地面积 = 用地面积 x 绿地率
```

不要默认“总建筑面积”等于“计容建筑面积”。地下空间、架空层、设备层、阳台等计入方式取决于当地规则。

## 户数与人口

```text
可分配住宅面积 = 住宅计容建筑面积 x 住宅效率系数
估算户数 = 可分配住宅面积 / 平均套内或建筑面积
估算人口 = 户数 x 户均人口
```

使用前明确住宅效率系数和户型面积是套内、建筑还是销售口径。

## 功能面积平衡

```text
某功能面积 = 总面积 x 功能占比
功能占比 = 某功能面积 / 总面积 x 100%
剩余面积 = 总面积 - 已分配功能面积之和
```

检查所有功能占比之和是否为 100%。若交通、设备或后勤另计，必须写明。

## 停车

按户数计：

```text
车位需求 = 户数 x 车位/户指标
```

按面积计：

```text
车位需求 = 计费面积 / 指标面积 x 每指标面积车位数
```

按床位、客房、座位或班级计：

```text
车位需求 = 基础数量 x 单位配建指标
```

车库面积初估：

```text
车库建筑面积 = 车位数 x 单车位综合建筑面积
```

分别计算机动车、无障碍车位、装卸位、访客位、充电位和非机动车位，不要用一个比例替代全部类别。

## 简化日照间距

仅在用户提供适用系数时使用：

```text
简化间距 = 有效遮挡高度 x 适用间距系数
```

该公式不能替代三维日照分析。朝向、地形、建筑宽度、窗位、当地日照日和连续时数要求都会改变结果。

## 容量与效率

```text
使用人数 = 可用面积 / 人均面积
净毛比 = 净使用面积 / 总建筑面积
交通与辅助面积 = 总建筑面积 - 净使用面积
面积效率 = 净使用面积 / 总建筑面积 x 100%
```

## 投资静态指标

```text
建安成本初估 = 建筑面积 x 单方造价
年租金收入 = 可出租面积 x 单位租金 x 计费周期
静态收益率 = 年净收入 / 总投资 x 100%
静态回收期 = 总投资 / 年净收入
```

造价、租金和空置率必须标注币种、地区、时间、含税口径和数据来源。

## 舍入建议

- 面积：方案阶段通常保留到 1 平方米或 0.1 平方米，按项目精度调整。
- 比率：通常保留 1 至 2 位小数。
- 人数、户数、车位、洁具：按适用规则取整；没有规则时说明采用向上取整。
- 金额：同时展示单价、数量、币种和价格时点。
