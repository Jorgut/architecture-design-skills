# 非规范性方案经验值

本文件只用于早期方案初估。以下范围不是法规，不代表任何城市的现行要求。使用时写明“经验值，待当地标准、任务书和顾问意见核验”。

## 停车空间初估

单个机动车位含通道、坡道和设备分摊的综合面积可先采用：

| 类型 | 初估范围 |
| --- | ---: |
| 地面停车 | 25-30 m2/车位 |
| 常规地下停车 | 30-40 m2/车位 |
| 机械停车 | 15-25 m2/车位 |

柱网、坡道数量、防火分区、人防、设备房和异形边界会显著改变结果。

## 商业功能配比

用于概念阶段容量测试的常见范围：

| 功能 | 建议测试范围 |
| --- | ---: |
| 零售 | 35%-55% |
| 餐饮 | 15%-30% |
| 娱乐与体验 | 10%-25% |
| 服务及其他 | 5%-20% |

先确认分母是否为可租赁面积、净使用面积或总建筑面积。

## 酒店功能配比

| 功能 | 建议测试范围 |
| --- | ---: |
| 客房区 | 50%-65% |
| 公共区 | 8%-15% |
| 餐饮区 | 8%-18% |
| 会议宴会 | 3%-12% |
| 康体娱乐 | 2%-8% |
| 后勤与运营 | 8%-18% |

酒店定位、客房数、宴会规模和运营品牌标准比通用比例更重要。

## 垂直交通初筛

办公项目可用以下目标做早期比较，不用于最终选型：

- 5 分钟运载能力：约占设计人数的 12%-20%。
- 平均候梯时间：根据建筑等级测试约 25-40 秒。

最终配置应由电梯交通分析确定，并纳入分区、层数、峰值模式和消防要求。

## 使用原则

1. 先展示经验值来源状态和适用限制。
2. 至少测试低、中、高三个情景。
3. 不用本文件判断法规合规。
4. 用户提供当地标准后，立即用正式数值替换经验值。
5. 对价格、造价、租金等快速失效的数据，不提供无日期的默认值。
